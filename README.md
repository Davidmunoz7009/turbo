# Turbo

Juego de carreras para iPhone desarrollado con SwiftUI y SpriteKit.

## Compilar la IPA

Abre la pestaña **Actions**, ejecuta **Build IPA** con **Run workflow** y descarga el artefacto **Turbo-ipa** cuando termine la compilación.

Requiere iOS 16 o superior. La IPA se genera sin firma y debe instalarse mediante una herramienta de sideloading compatible.

Controles: desliza a izquierda o derecha para mover el coche y esquivar el tráfico.
